# handoff — скилл передачи сессии для любого ИИ-агента

[English version](README.md)

`handoff` превращает любую чат-сессию с ИИ-агентом в исчерпывающий
`HANDOFF.md`, по которому другой агент (или человек) продолжит работу, не видя
сессии: история задачи, что сделано и что нет, что получалось и что
проваливалось, состояние файлов, команды воспроизведения, грабли окружения,
открытые вопросы вам (Q1..Qn с вариантами ответов) и следующие шаги.

Один исходный файл — [`SKILL.md`](SKILL.md) — работает как обычный скилл в
агентах с поддержкой формата `SKILL.md` и как инструкция во всех остальных.
Зависимостей нет, к внутренним API конкретного агента он не привязан.

Как выглядит результат: [`examples/HANDOFF.example.md`](examples/HANDOFF.example.md).

## Как пользоваться

После установки попросите агента в конце сессии или после крупного этапа:

> сделай хэндоф

или своими словами — «передай контекст другому агенту», «сделай выжимку
сессии», «зафиксируй прогресс». Документ пишется на языке сессии.

Агент запишет `HANDOFF.md` в корень проекта (или обновит существующий),
сверит факты с файловой системой, замаскирует секреты и ответит путём к файлу
и числом открытых вопросов. Отвечайте коротко («Q1-а, Q3-б») — агент обновит
документ.

## Установка

### Через агента

Вставьте это в Claude Code, Codex или другой агент с доступом к файлам:

```text
Поставь скилл handoff из https://github.com/gman-dev-nov/handoff-skill:
скопируй его SKILL.md в папку скиллов, которую читает твой харнес
(внутри неё — handoff/SKILL.md), и скажи, как его вызывать.
```

### Claude Code

```bash
mkdir -p ~/.claude/skills/handoff
curl -fsSL https://raw.githubusercontent.com/gman-dev-nov/handoff-skill/main/SKILL.md -o ~/.claude/skills/handoff/SKILL.md
```

Вызов — `/handoff` или любая из фраз выше.

### Codex, ZCode и другие агенты, читающие `~/.agents/skills`

```bash
mkdir -p ~/.agents/skills/handoff
curl -fsSL https://raw.githubusercontent.com/gman-dev-nov/handoff-skill/main/SKILL.md -o ~/.agents/skills/handoff/SKILL.md
```

### Другие агенты с поддержкой `SKILL.md`

Положите `SKILL.md` в `handoff/SKILL.md` внутри папки скиллов из документации
вашего агента. Файл — стандартный скилл: YAML-frontmatter с `name` и
`description`, дальше инструкция.

### Чат-ассистенты без скиллов (ChatGPT, Gemini, любой LLM)

Используйте [`system-prompt.md`](system-prompt.md) — та же инструкция без
frontmatter скилла:

- вставьте её в инструкции Custom GPT, проекта, Gem или аналога
  (5,5 тыс. символов, укладывается в лимит Custom GPT в 8 тыс.);
- или задайте системным промптом при вызове модели через API;
- или отправьте первым сообщением: «Следуй этой инструкции, когда я попрошу
  handoff».

Без файловых инструментов ассистент выдаст документ одним блоком кода, чтобы
вы сохранили его сами.

## Разработка

Редактируется только `SKILL.md`. `system-prompt.md` генерируется из
него (то же тело без frontmatter) — руками его не править.

```bash
python3 build.py            # пересобрать system-prompt.md
python3 build.py --install  # плюс скопировать SKILL.md в ~/.agents/skills и ~/.claude/skills
python3 build.py --check    # для CI: ошибка, если файл устарел или превышен лимит
```

Правите `SKILL.md` → `python3 build.py` → коммитите оба файла. CI запускает
`--check` на каждый push и pull request.

## Почему скилл, а не плагин

Плагин собирает несколько скиллов, команд, хуков или MCP-серверов. Здесь один
workflow и один документ на выходе — хватает одного `SKILL.md`, и он
переносится между агентами.
